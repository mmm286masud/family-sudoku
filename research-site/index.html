Technical Decisions

I plan to use HTML, CSS and JavaScript for the frontend, Python Flask for the backend, and SQLite for data storage.

Technology Comparisons

Flask vs. Django

Flask is a lightweight Python web framework that gives developers flexibility in organizing their applications. Django provides more built-in functionality, including an authentication system and an admin interface.

My choice: Flask. Family Sudoku is a relatively small application, so I prefer Flask's simpler structure. I understand that I will need to implement or integrate some security and account features.

Django Documentation

SQLite vs. PostgreSQL

SQLite is a database engine that does not require a separate database server. PostgreSQL is a database server that offers more advanced capabilities for applications with larger workloads.

My choice: SQLite. It is simpler for initial development and testing. I will need to verify that my hosting environment supports persistent SQLite storage.

PostgreSQL Documentation

Plain JavaScript vs. React

Plain JavaScript can directly manage interactions with the Sudoku board. React provides a component-based approach for building user interfaces.

My choice: Plain JavaScript. I expect Family Sudoku's interface to be manageable without introducing an additional frontend framework.
