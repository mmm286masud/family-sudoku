Project Overview

Family Sudoku is a web-based puzzle game that replaces traditional Sudoku numbers with nine family characters. The target audience is players of all ages.

Research Question

How can I build a secure, interactive Sudoku game that saves player progress while keeping the application simple and maintainable?

This website will document my research, technology comparisons, sources and findings.

Technical Decisions

I plan to use HTML, CSS and JavaScript for the frontend, Python Flask for the backend, and SQLite for data storage.

These choices are currently part of my project plan and will be evaluated during implementation.

Planned Experiment

I will compare drag-and-drop character placement with click-to-select placement to determine which method is easier to use.

Status: Planned, not yet tested.
