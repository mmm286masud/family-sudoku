# Family Sudoku

## Project Overview
Family Sudoku is a web-based Sudoku puzzle game that replaces traditional numbers with nine different family characters. The goal is to make Sudoku more visually engaging and enjoyable for players of all ages.

## Alternative Project Idea
Memory Time Capsule is a non-game application where users can save personal memories, photos, messages, and goals in digital time capsules.

I chose Family Sudoku because it combines classic puzzle-solving with a unique visual design and has a manageable scope.

## Target Audience
People of all ages who enjoy Sudoku and casual puzzle games.

## Planned Features
- User registration and login
- 9x9 Sudoku puzzles with family characters
- Save and resume unfinished games
- Private dashboard with completed puzzles and best times
- Account settings to update user information

## Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Testing: pytest
- Version Control: GitHub
- Research Website: GitHub Pages

## Creative Experiment
Compare drag-and-drop character placement with click-to-select placement to determine which method is easier for players.

## Project Status
Planning stage. Features and tests are planned, not yet implemented.
